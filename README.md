# DSA Cinema Project

## Cách build và chạy chương trình

### Trên Windows (Git Bash, MSYS2, MinGW)
Mở terminal trong thư mục dự án, sau đó chạy:

```bash
Build: g++ -g src/main.cpp src/utils.cpp src/cinema/CinemaSystem_Booking.cpp src/cinema/CinemaSystem_Cancel.cpp src/cinema/CinemaSystem_Data.cpp src/cinema/CinemaSystem_Display.cpp src/cinema/CinemaSystem_Main.cpp src/cinema/CinemaSystem_Sort.cpp -o main.exe

Run: ./main.exe
